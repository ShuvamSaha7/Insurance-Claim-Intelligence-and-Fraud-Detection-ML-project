# Insurance-Claim-Intelligence-and-Fraud-Detection-ML-project
Health Insurance Claims Analysis and Fraud Detection using Python, Machine Learning, clustering, and PCA to identify potentially fraudulent claims.

## 📌 Overview

An end-to-end Machine Learning project that analyzes health insurance claims and identifies potentially fraudulent claims using supervised and unsupervised learning techniques.

## 🎯 Objectives

* Perform data cleaning and Exploratory Data Analysis (EDA).
* Engineer features and identify important fraud indicators.
* Compare multiple machine learning classification models.
* Apply clustering and PCA for pattern discovery and dimensionality reduction.
* Evaluate models using Accuracy, Precision, Recall, and F1-score.

## 🛠️ Technologies Used

* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
* **Environment:** Jupyter Notebook

## 🤖 Algorithms Implemented

**Supervised Learning:** Logistic Regression, Decision Tree, Random Forest, KNN, SVM, Gradient Boosting.

**Unsupervised Learning:** K-Means, Hierarchical Clustering, DBSCAN, PCA.

## 📊 Dataset

The dataset contains 4,500 health insurance claims, including claim details, patient information, and fraud labels. It covers July 2022 to July 2024.

## ⚠️ Disclaimer

The dataset appears to contain synthetic patterns. High model scores may not reflect real-world fraud detection performance. Independent validation is required before practical use.
